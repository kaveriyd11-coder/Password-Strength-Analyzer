# Password Strength Analyzer

## Project Overview

Password Strength Analyzer is a Python-based tool that evaluates password strength using basic security checks.

## Features

- Checks password length.
- Checks uppercase and lowercase letters.
- Checks numbers and special characters.
- Classifies password strength.
- Suggests ways to improve weak passwords.
- Generates random passwords using Python's secure random module.

## Technologies Used

- Python
- Visual Studio Code
- Python Standard Library

## How to Run

1. Install Python.
2. Download this project.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the command:

```bash
python password_analyzer.py
```

6. Follow the menu displayed in the terminal.

## Learning Outcomes

This project demonstrates Python functions, conditional statements, string operations, and secure random password generation.

## Disclaimer

This is an educational project. Its password strength classification is basic and does not guarantee password security.
